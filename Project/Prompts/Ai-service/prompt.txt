# Five S Prompt — Refactor AI-Service

## Scope

Refactor AI-service cho hệ thống scheduler/goals với kiến trúc dễ mở rộng, clean architecture và fallback AI provider.

## Structure

Backend:

* Quản lý cấu hình model của Gemini và OpenAI tách biệt.
* Hỗ trợ nhập liệu bằng ngôn ngữ tự nhiên:

  * Ví dụ: “Tôi có cuộc họp vào ngày mai lúc 8h”.
  * AI tự phân tích và map thành schedule/task tương ứng.
* Hỗ trợ nhập liệu bằng hình ảnh:

  * Upload ảnh lịch trình/hóa đơn/note.
  * Dùng Structured Output để trích xuất dữ liệu từ schedule-service.
* Nếu thiếu dữ liệu bắt buộc:

  * Trả về danh sách field còn thiếu rõ ràng.
* Nếu Gemini hết quota hoặc lỗi:

  * Tự động fallback sang OpenAI.

Frontend:

* Tại trang scheduler/goals có floating AI button hình tròn.
* Cho phép:

  * nhập text tự nhiên,
  * upload image,
  * preview kết quả schedule trước khi lưu.
* UI tối giản, realtime loading và hiển thị lỗi thân thiện.

## Style

* Ưu tiên TypeScript, service-based architecture.
* Tách provider Gemini/OpenAI theo strategy pattern.
* Validation rõ ràng, dễ maintain.
* API response thống nhất.

## Safety

* Validate input/image upload.
* Handle timeout, quota limit, malformed structured output.
* Không hardcode API key.
* Logging và error handling đầy đủ.

## Success

* AI tạo đúng lịch từ text/image.
* Fallback provider hoạt động ổn định.
* Code modular, dễ mở rộng thêm AI provider mới.
* Frontend UX đơn giản và trực quan.
