Refactor frontend architecture theo phương pháp Five S:

1. Sort
Xóa `package-lock.json`, chỉ sử dụng `pnpm` và giữ `pnpm-lock.yaml`.
Loại bỏ cấu trúc thư mục dư thừa hoặc trùng chức năng.

2. Set in Order
Gộp toàn bộ custom hooks về `src/hooks`.
Tạo `src/store` chứa `auth-store.ts`, `ui-store.ts`.
Đưa toàn bộ logic gọi backend vào `src/services` hoặc đổi tên thành `src/api`.
`src/lib` chỉ chứa utility/config dùng chung như `api-client.ts`, `schemas.ts`, `providers.tsx`.

3. Shine
Refactor import path theo cấu trúc mới.
Xóa code chết, duplicate hooks/services.
Chuẩn hóa naming convention và barrel export nếu cần.

4. Standardize
Đồng bộ kiến trúc frontend theo cấu trúc:
src/
├── app/
├── components/
├── hooks/
├── store/
├── services/
├── lib/
├── types/

Đảm bảo toàn bộ team chỉ dùng `pnpm`.

5. Sustain
Cập nhật ESLint/tsconfig alias/import rules để enforce structure mới.
Thêm guideline ngắn trong README về convention thư mục và package manager.
