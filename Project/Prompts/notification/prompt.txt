# Five S Prompt — Chức năng thông báo nhắc lịch sắp đến hạn

## Scope

Xây dựng chức năng notification/reminder cho hệ thống scheduler để tự động nhắc người dùng khi task/schedule sắp đến hạn trong vòng 3 ngày trở lại.

## Structure

Backend:

* Tạo Notification module bằng NestJS.
* Cron job chạy định kỳ kiểm tra task sắp hết hạn.
* Điều kiện:

  * `deadline <= 3 ngày`
  * task chưa hoàn thành.
* Tạo notification tương ứng cho user.
* Tránh gửi trùng notification.
* Hỗ trợ mở rộng realtime notification bằng WebSocket hoặc Firebase sau này.

Frontend:

* Hiển thị notification bell/icon.
* Có danh sách thông báo sắp đến hạn.
* Highlight task nguy cấp:

  * 3 ngày → warning.
  * 1 ngày → danger.
* Click notification điều hướng đến task tương ứng.

## Style

* Sử dụng NestJS + Prisma Client.
* Clean architecture, module tách biệt.
* Notification service reusable và dễ mở rộng.
* API response thống nhất.
* UI tối giản, realtime-friendly.

## Safety

* Không gửi notification trùng lặp.
* Handle timezone chính xác.
* Chỉ gửi cho owner/member hợp lệ.
* Cron job không gây overload database.
* Validate task status trước khi gửi.

## Success

* User nhận được nhắc lịch tự động trong vòng 3 ngày trước deadline.
* Notification hiển thị đúng frontend.
* Không có duplicate reminder.
* Hệ thống hoạt động ổn định với số lượng task lớn.
