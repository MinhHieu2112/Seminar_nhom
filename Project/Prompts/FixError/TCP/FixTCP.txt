Mục tiêu: Fix lỗi API Gateway chạy local không gọi được microservices trong Docker (hybrid mode).

Bối cảnh:

* API Gateway chạy trên máy thật.
* Các microservices chạy trong Docker Compose.
* Gateway đang dùng hostname kiểu `scheduler-service`, `calendar-service` nên máy thật không resolve được.
* Một số service chưa expose port ra ngoài.

Yêu cầu:

1. Sửa `docker-compose.yml`:

   * Expose port cho các service cần Gateway truy cập.
   * Ví dụ:

     ```yml
     scheduler-service:
       ports:
         - "8001:8001"

     calendar-service:
       ports:
         - "8002:8002"
     ```

2. Sửa file `.env` của API Gateway local:

   * Đổi host từ tên container sang `localhost`.
   * Ví dụ:

     ```env
     SCHEDULER_SERVICE_HOST=localhost
     CALENDAR_SERVICE_HOST=localhost
     ANALYTICS_SERVICE_HOST=localhost
     ```

3. Giải thích ngắn gọn nguyên nhân lỗi:

   * Máy thật không resolve được hostname Docker nội bộ.
   * Service chưa publish port ra ngoài host machine.

4. Đảm bảo Gateway local có thể gọi TCP/HTTP tới service Docker sau khi sửa.
